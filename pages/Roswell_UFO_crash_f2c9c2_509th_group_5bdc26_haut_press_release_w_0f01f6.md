## Introduction

Walter Haut's press release is the single most important contemporary document in the Roswell story because it represents the earliest official public statement issued by the military itself. On 8 July 1947, acting as the public information officer at [Roswell Army Air]({{ 'roswell-army-air/' | relative_url }}) Field, First Lieutenant Walter G. Haut distributed a short announcement stating that the intelligence office of the 509th Bombardment Group had recovered a "[flying disc]({{ 'flying-disc/' | relative_url }})" with the assistance of a local rancher and the Chaves County sheriff. Within hours, higher headquarters replaced that account with the explanation that the recovered material was a weather balloon. The resulting contradiction has made Haut's announcement the central documentary evidence in the Roswell controversy, not because it proves what was recovered, but because it records exactly what the local command believed—or was prepared to announce—before the public narrative changed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.altmystery.com/article/roswell-1947/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: altmystery.com">[AltMystery]</a><span class="citation-popover" role="note"><span class="citation-popover-source">altmystery.com</span><span class="citation-popover-title">roswell 1947</span><span class="citation-popover-snippet">Roswell 1947 &amp; Area 51 · AltMysteryMay 26, 2026...</span><span class="citation-popover-meta">Published: May 26, 2026</span></span></span>

## What the release stated as fact

The wording is notable because it made several affirmative factual claims rather than merely repeating local rumours.

First, it declared that the intelligence office of the 509th Bombardment Group had "gained possession of a disc." It did not describe the object as an [unidentified]({{ 'unidentified/' | relative_url }}) report awaiting investigation; instead, it presented the recovery as an accomplished fact.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.altmystery.com/article/roswell-1947/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: altmystery.com">[AltMystery]</a><span class="citation-popover" role="note"><span class="citation-popover-source">altmystery.com</span><span class="citation-popover-title">roswell 1947</span><span class="citation-popover-snippet">Roswell 1947 &amp; Area 51 · AltMysteryMay 26, 2026...</span><span class="citation-popover-meta">Published: May 26, 2026</span></span></span>

Second, the release identified the chain of custody. It credited cooperation between a local rancher and the Chaves County Sheriff's Office before explaining that Major Jesse Marcel recovered the material and that it was sent onwards to higher headquarters. This description established that the object was being treated as a military intelligence matter rather than remaining with civilian authorities.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufologie.patrickgross.org/rw/p/seattledailytimes8jul1947.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOS at close sight: The Roswell 1947 incident in the Press, The Seattle Daily Times, July 8, 1947...</span><span class="citation-popover-meta">Published: July 8, 1947</span></span></span>

Third, despite the dramatic headline that followed in newspapers, the release itself contained remarkably little description of the object's appearance. It did not discuss size, shape, construction or performance. Instead, the key descriptive word was simply "disc" or "flying disc", terminology already widespread during the nationwide "flying saucer" wave that began after Kenneth Arnold's widely reported sighting in June 1947.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.altmystery.com/article/roswell-1947/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: altmystery.com">[AltMystery]</a><span class="citation-popover" role="note"><span class="citation-popover-source">altmystery.com</span><span class="citation-popover-title">roswell 1947</span><span class="citation-popover-snippet">Roswell 1947 &amp; Area 51 · AltMysteryMay 26, 2026...</span><span class="citation-popover-meta">Published: May 26, 2026</span></span></span>

## Why the word "disc" matters

The term "flying disc" has become one of the most debated elements of the document.

In 1947, "flying disc" was the standard expression used by newspapers and military personnel to describe reported unidentified aerial objects. It did not necessarily imply that investigators had performed a technical examination proving the recovered material was an extraordinary craft. Rather, it reflected the vocabulary of the day during an intense period of public speculation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.altmystery.com/article/roswell-1947/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: altmystery.com">[AltMystery]</a><span class="citation-popover" role="note"><span class="citation-popover-source">altmystery.com</span><span class="citation-popover-title">roswell 1947</span><span class="citation-popover-snippet">Roswell 1947 &amp; Area 51 · AltMysteryMay 26, 2026...</span><span class="citation-popover-meta">Published: May 26, 2026</span></span></span>

For historians, this distinction is important. The release demonstrates that Roswell Army Air Field publicly adopted the prevailing "flying disc" terminology before the object reached higher headquarters. Whether that language reflected genuine belief, incomplete information, misunderstanding or haste is a separate question that cannot be answered from the press release alone.

## What happened after the announcement

The announcement had an exceptionally brief public life.

After the story appeared on news wires, Brigadier General Roger Ramey at Fort Worth Army Air Field announced that the recovered material was not a flying disc but the remains of a weather balloon and radar target. Photographs of Major Jesse Marcel with balloon debris were released to the press, effectively replacing Haut's original statement with the balloon explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufologie.patrickgross.org/rw/p/seattledailytimes8jul1947.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOS at close sight: The Roswell 1947 incident in the Press, The Seattle Daily Times, July 8, 1947...</span><span class="citation-popover-meta">Published: July 8, 1947</span></span></span>

The speed of this reversal is one reason the original release remains historically significant. It preserves a snapshot of the local command's public position before intervention from higher headquarters, allowing researchers to compare the two official accounts issued on the same day.

## What later retellings added or changed

As Roswell became the subject of books, documentaries and witness recollections decades later, the original press release was frequently expanded beyond what it actually said.

Common additions include claims that the release:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* described a crashed extraterrestrial spacecraft;
* referred to alien bodies;
* detailed unusual materials or technologies; or
* explicitly stated that the object had crashed.

</div>

None of those claims appears in the surviving wording distributed by Walter Haut. The announcement simply reported possession of a "flying disc", explained how military personnel acquired it and noted that it had been forwarded to higher headquarters.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.altmystery.com/article/roswell-1947/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: altmystery.com">[AltMystery]</a><span class="citation-popover" role="note"><span class="citation-popover-source">altmystery.com</span><span class="citation-popover-title">roswell 1947</span><span class="citation-popover-snippet">Roswell 1947 &amp; Area 51 · AltMysteryMay 26, 2026...</span><span class="citation-popover-meta">Published: May 26, 2026</span></span></span>

Similarly, later statements by Walter Haut—including his posthumously released affidavit describing what he said he later learned or witnessed—are historically distinct from the July 1947 press release itself. Those later recollections have become part of the broader Roswell debate, but they should not be read back into the text of the original announcement, which remains a short operational news release with much narrower claims.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.dallasobserver.com/news/contact-6389022/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: dallasobserver.com">[Dallas Observer]</a><span class="citation-popover" role="note"><span class="citation-popover-source">dallasobserver.com</span><span class="citation-popover-title">Dallas Observer Contact &#124; Dallas Observer</span><span class="citation-popover-snippet">Dallas ObserverContact &#124; Dallas ObserverApril 3, 2003...</span><span class="citation-popover-meta">Published: April 3, 2003</span></span></span>

## Why the release remains the key documentary evidence

The value of Walter Haut's release lies less in what it proves than in what it unquestionably records.

It establishes that:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* the statement originated from Roswell Army Air Field's public information office;
* it was issued under the authority of the local command;
* it identified the 509th Bombardment Group's intelligence office as having recovered a "flying disc";
* it documented transfer of the recovered material to higher headquarters; and
* it was superseded within hours by a different official explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.altmystery.com/article/roswell-1947/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: altmystery.com">[altmystery.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">altmystery.com</span><span class="citation-popover-title">roswell 1947</span><span class="citation-popover-snippet">Roswell 1947 &amp; Area 51 · AltMysteryMay 26, 2026...</span><span class="citation-popover-meta">Published: May 26, 2026</span></span></span>

</div>

Those uncontested documentary facts explain why the Haut release continues to occupy such a central place in discussions of the [Roswell incident]({{ 'the-1980-book/' | relative_url }}). Regardless of later interpretations, it remains the earliest surviving official announcement that shaped the controversy and the benchmark against which every subsequent account has been compared.

      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
